# 这个主页为什么坚持零构建

现代前端工具链很强，但个人主页的核心需求通常很朴素：稳定展示、方便修改、低维护成本。对这个目标而言，普通 HTML、CSS 和 JavaScript 已经足够。

## 零构建带来的收益

- 不需要安装 Node.js、npm 或 pnpm。
- 不存在依赖升级导致的构建失败。
- GitHub Pages 可以直接从分支发布。
- 内容文件可直接在 GitHub 网页端编辑。
- 站点结构透明，任何静态托管服务都能迁移。

## 内容如何组织

个人信息、荣誉和资源集中在 `content/site.js`；博客目录集中在 `content/blogs.js`；文章正文使用独立 Markdown 文件。增加内容只需要复制一个对象或新增一个 `.md` 文件。

## 仍然保留的现代体验

零构建并不等于简陋。这个主页仍然具备响应式布局、平滑导航、筛选搜索、文章弹窗、设计 token、键盘操作以及无障碍属性。复杂度被放在一次性的基础代码中，而不是留给每次内容更新。
